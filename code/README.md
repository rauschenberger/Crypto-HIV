
# TLFs

Next to the general SAS scripts for all domains (see [README.md](../README.md)), this directory contains a specific SAS script for each domain to generate tables, figures, and listings.

- [DM](tlf_dm.sas): demographics
- [MH](tlf_mh.sas): medical history
- [PM](tlf_pm.sas): prior medications
- [IE](tlf_ie.sas): ineligibility
- [DV](tlf_dv.sas): protocol deviations
- [DS](tlf_ds.sas): disposition milestones
- [DI](tlf_di.sas): discharge
- [ART](tlf_art.sas): ART initiation
- [ARTT](tlf_artt.sas): ART treatment
- [EX](tlf_ex.sas): treatment exposure
- [DA](tlf_da.sas): drug accountability
- [CM](tlf_cm.sas): concomitant medications
- [CE](tlf_ce.sas): current symptoms
- [AE](tlf_ae.sas): adverse events
- [PE](tlf_pe.sas): physical examination
- [VS](tlf_vs.sas): vital signs
- [GC](tlf_gc.sas): Glasgow coma score
- [LP](tlf_lp.sas): lumbar punctures
- [LB](tlf_lb.sas): laboratory
- [EG](tlf_eg.sas): electrocardiogram
- [RANKIN](tlf_rankin.sas): Rankin disability questionnaire
- [DD](tlf_dd.sas): death details
- [PR](tlf_pr.sas): pregnancy
- [EQ](tlf_eq.sas): quality of life
- [QUEST](tlf_quest.sas): palatability acceptability
- [PC](tlf_pc.sas): pharmacokinetics
